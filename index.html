WalkWithMe

🧭 Project Overview

WalkWithMe is a web-based platform designed to enhance campus safety by connecting students with verified walking companions. It helps students find trustworthy partners for late-night or long-distance walks across campus.

⚙️ Key Features

  • User registration and login
  • Request and accept walk companionship
  • Admin interface for managing users and safety logs
  • Notification system for status updates
